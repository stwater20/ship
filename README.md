# 戰艦大和 Yamato — Tidebreaker

瀏覽器 3D 戰艦遊戲（Three.js，純靜態檔案，可直接部署到 GitHub Pages）。

- Gerstner 波浪海洋（CPU / GPU 同步浮力）、海岸浪花、尾流與艏浪
- 46cm 三聯裝主砲 ×3、副砲：滑鼠瞄準、彈道計算、水柱與爆炸
- 日夜循環、晴朗 / 起浪 / 暴風雨（雨、閃電、雷聲）
- 12 個檢查點計時賽、標靶船、補給、海豚、海鷗、燈塔

## 操作
| 按鍵 | 功能 |
| --- | --- |
| W / S | 前進 / 倒車 |
| A / D | 轉舵 |
| 滑鼠 + 左鍵 / F | 瞄準、主砲齊射 |
| 右鍵 | 副砲 |
| Shift | 鍋爐增壓 |
| C / T / N | 視角 / 天氣 / 時間快轉 |
| H / R / P / M | 汽笛 / 回起點 / 暫停 / 靜音 |

手機支援虛擬搖桿。

## 本機執行
```bash
python3 -m http.server 8000
```
開啟 http://localhost:8000

網址參數：`?play&cam=3&tod=18&weather=2`
