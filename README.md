# 戰艦大和 Yamato — Tidebreaker

瀏覽器 3D 戰艦遊戲（Three.js，純靜態檔案，可直接部署到 GitHub Pages）。

- Gerstner 波浪海洋（CPU / GPU 同步浮力）、海岸浪花、尾流與艏浪
- 46cm 三聯裝主砲 ×3、副砲：滑鼠瞄準、彈道計算、水柱與爆炸
- 日夜循環、晴朗 / 起浪 / 暴風雨（雨、閃電、雷聲）
- **海戰模式（預設）**：敵艦隊一波波來襲
  - 驅逐艦：高速繞圈、發射扇形魚雷（白色氣泡航跡）
  - 巡洋艦：三連砲火覆蓋，海面紅圈＝敵彈預計落點，看到就轉舵閃
  - 每 5 波出現敵旗艦（魔王）
  - 準星靠近敵艦會自動鎖定並計算提前量；副砲可擊毀魚雷；衝撞也能擊沉驅逐艦
  - 艦體血量、受損起火、連擊加分、波次獎勵與修理、最高分紀錄、沉沒結算
- **台灣環島觀光**（選單「台灣觀光」或網址 `?tour`）
  - 依真實經緯度建出的台灣本島（中央山脈、東海岸斷崖、西部平原）與澎湖、小琉球、綠島、蘭嶼、龜山島
  - 22 個海岸與離島景點，開到金色光柱就算抵達，跳出景點介紹、官方觀光網站與 Google 地圖連結
  - 集章紀錄保存在瀏覽器；按 L 打開全台景點地圖選擇下一站
- 計時賽模式：12 個檢查點、標靶船
- 補給、海豚、海鷗、燈塔

## 操作
| 按鍵 | 功能 |
| --- | --- |
| W / S | 前進 / 倒車 |
| A / D | 轉舵 |
| 滑鼠 + 左鍵 / F | 瞄準、主砲齊射 |
| 右鍵 | 副砲 |
| Shift | 鍋爐增壓 |
| C / T / N | 視角 / 天氣 / 時間快轉 |
| H / R / P / M | 汽笛 / 重來 / 暫停 / 靜音 |

手機支援虛擬搖桿。

## 本機執行
```bash
python3 -m http.server 8000
```
開啟 http://localhost:8000

網址參數：`?tour`（台灣觀光）、`?play`（海戰）、`?play=race`（計時賽）、`&cam=3&tod=18&weather=2`
